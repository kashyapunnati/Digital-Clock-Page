# Digital Clock

## 📌 Project Description

This project is a simple Digital Clock created using HTML5, CSS3, and JavaScript. It displays the current time in `HH:MM:SS` format and updates automatically every second.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Displays current hours, minutes, and seconds
- Uses the JavaScript `Date` object
- Automatically updates every second using `setInterval()`
- Displays leading zeros for single-digit values
- Simple and responsive design

## 📂 Project Files

- `digitalclock.html` — Main HTML webpage
- `style.css` — Styling and layout
- `script.js` — Digital clock functionality

## ⚙️ How It Works

The JavaScript `Date` object gets the current time. The `getHours()`, `getMinutes()`, and `getSeconds()` methods extract the time values. The `setInterval()` function updates the clock every 1000 milliseconds.

## 🎯 Outcome

A functional digital clock webpage that displays the current time and updates automatically every second.
